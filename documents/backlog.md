## A. Prompt and taxonomy — next prompt revision (target 3.9.6)
**A decided call becomes a rule only when it passes three tests** (decided 2026-11-23, replacing "every decided call
becomes a rule"): (1) it can be stated without the protocol's own words — structure and geometry, not content; (2) it
describes an SoA pattern expected in other protocols, not one observed case; (3) a check can verify it, or it follows
from rules already in the prompt. Otherwise it stays a correction in that protocol's sidecar. Prompt acceptance
measures rules: a decided outcome with no rule behind it is an accepted delta, carried by corrections. Where an older
decision conflicts with a later general rule, the rule wins and the decision is re-decided in the sidecar. Every
prompt edit: version bump, `tools/redaction/apply_redactions.py` re-run (fails if a logged span no longer matches), gate
check 14 then requires the new version on new runs only.
